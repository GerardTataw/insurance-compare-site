Insurance Compare Site
======================

A simple, responsive website for comparing insurance quotes from multiple providers.

## Project Structure

- index.html       - Homepage with features and insurance types
- compare.html     - Quote comparison form
- contact.html     - Contact information and contact form
- styles.css       - All styles for the website
- assets/          - Directory for images and other assets

## Features

- Responsive design that works on all devices
- Clean, modern UI with a professional color scheme
- Quote comparison form with multiple insurance types
- Contact page with FAQ section
- Easy to customize and extend

## How to Use

1. Open index.html in a web browser to view the website
2. All pages are linked together through the navigation menu
3. Contact form is configured to work with Netlify Forms

## Netlify Deployment

This site is configured for Netlify deployment:

1. Push your code to GitHub/GitLab/Bitbucket
2. Connect your repository to Netlify
3. Netlify will automatically detect the configuration from netlify.toml
4. The contact form will automatically work - view submissions in Netlify dashboard under Forms
5. Configure form notifications in Netlify dashboard (email, Slack, webhook)

Form submissions will appear in your Netlify dashboard at:
Site Settings > Forms > Active forms > contact

## Customization

- Colors can be changed in the :root section of styles.css
- Add your logo to assets/logo.svg and update the header
- Customize form fields in compare.html as needed
- Add actual form submission logic with JavaScript or backend integration

## Browser Support

Works on all modern browsers:
- Chrome
- Firefox
- Safari
- Edge
